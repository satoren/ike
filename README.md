# ike（池づくり）

ブラウザで動く、3D 見下ろし型の自然環境づくり・運営ゲームです。
地面を掘って池を作り、木を植えて自然を育てます。

## 遊びの仕組み

- **収入は 2 つ。** 1 つは、木に実った果物や、集まってきた動物（ウサギ・カモ・キツネ）、水生生物（サカナ）を「集める」でかごに入れて売ること。もう 1 つは、景観の魅力に応じた来園者の入園料（ゲーム内の 1 日ごと）
- **採りすぎると魅力が下がる。** 魅力には、いま実っている果物や暮らしている生き物も含まれる。採るほど「荒らされ度」がたまって魅力が下がり、時間がたつと回復する
- **肉食動物が来る。** ウサギが増えるとキツネが集まり、ウサギを食べる。キツネがいると来園者が襲われることがあり、そうなると魅力が大きく下がる（数日かけて回復）
- **来園者は出入口から出入りする。** 地図の手前（南端）に出入口があり、来園者はそこから入って遊歩道を散策し、また出入口から帰る。出入口とつながっていない道は灰色で表示され、安全度にも眺めにも数えない
- **クマが出る。** 3 日目以降、日が変わるときに地図の端からクマが現れることがある（森が育つほど出やすい）。クマは柵ごと遊歩道を壊しながら来園者へ向かい、襲うと魅力が大幅に下がる（最大 90%）。罠（クマ・キツネがかかる）を仕掛けるか、銃で撃って狩るまで居座る。狩ったクマは売れる
- **遊歩道で客を守る。** 柵付きの遊歩道にはキツネが入れない。来園者の数に見合う長さ（1 マスで 3 人）があれば客は安全に回れる。安全が足りないと魅力が最大 25% 下がる。水辺の道ほど眺めが良く、魅力が上がる。池の上に敷くと木道になる

## 技術構成

- [Three.js](https://threejs.org/)：3D 描画
- TypeScript + [Vite](https://vite.dev/)：開発・ビルド
- [Vitest](https://vitest.dev/)：ロジックのテスト
- UI は three.js ではなく普通の HTML/CSS で作る（運営ゲームは UI が多いため）

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173 で開く
npm test         # テスト
npm run build    # dist/ に静的ファイルを出力（どこの静的ホスティングにも置ける）
```

## 確認用

URL に `?bear` を付けると、最初からクマが 1 頭出ます。

## 操作

| 操作 | 内容 |
|---|---|
| 1〜9 / ツールバー | 移動・掘る・盛る・ならす・植える・遊歩道・集める・罠・銃 |
| Shift + 左ドラッグ | 遊歩道を撤去 |
| 左ドラッグ | 選んだ道具を使う（「移動」ではカメラ移動） |
| 右ドラッグ | カメラ移動 |
| 中ドラッグ | カメラ回転 |
| ホイール | ズーム |
| `[` / `]` | ブラシの大きさ |

## コードの構成

| ファイル | 役割 |
|---|---|
| `src/heightmap.ts` | 地形の高さデータと、掘る・盛る・ならすブラシ（描画から独立） |
| `src/terrain.ts` | 高さデータを three.js のメッシュにして、高さに応じて色を塗る |
| `src/water.ts` | 地下水位の水面。これより低い地面が池として見える |
| `src/trees.ts` | 木と果物を InstancedMesh でまとめて描く。若木は育ち、水没した木は消える |
| `src/ecology.ts` | 生態系：木の実り、生き物の集まり方と動き、キツネの狩り、採りすぎ・襲撃・安全度を含む魅力の計算 |
| `src/economy.ts` | 道具の費用と、すみかの状態（池の広さ・水辺の木）の集計 |
| `src/creatures.ts` | ウサギ・カモ・サカナ・キツネの見た目 |
| `src/bears.ts` / `src/bearview.ts` | クマの出没・移動・破壊・襲撃、罠と銃（ロジック）と、その見た目 |
| `src/paths.ts` | 出入口と柵付きの遊歩道（つながりの判定・見た目）、出入口から入って帰る来園者 |
| `src/ui.ts` / `src/style.css` | HTML の UI |
| `src/main.ts` | シーン、カメラ、入力、ゲームループ |

## 今後のアイデア

- 水を一定の水位ではなく、流れて溜まるシミュレーションにする（川・滝・水の供給源）
- 水質・植生による生態系のバランス、生き物の種類を増やす
- 売値の相場（たくさん売ると値下がり）
- 草花・水草・岩・小道・ベンチなどの配置物
- セーブ／ロード（localStorage）
